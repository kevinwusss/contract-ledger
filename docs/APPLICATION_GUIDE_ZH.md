# 英国硕士申请展示说明

## 项目定位

建议名称：Contract Ledger - Local-First Contract and Finance Management。

可以展示业务需求分析、Python/Flask、SQL 数据建模、数据质量控制、OCR 集成与软件测试。不要把它描述为自行训练的大模型、成熟商业 SaaS 或已经完成全部企业级能力的平台。页面目前仍为中文，英文 README 和演示指南帮助审阅者理解。

## 如何写入申请

先逐项写清自己的实际贡献，再形成英文描述。可采用以下事实约束下的句式，只有真正完成相应工作才使用：

> Developed an AI-assisted Python/Flask portfolio project for contract archiving and financial reconciliation, integrating local OCR, human verification, SQLite records and automated workflow tests.

如果你主要负责需求梳理、测试和修改决策，应改为：

> Defined business requirements and evaluated an AI-assisted contract-management prototype, focusing on document traceability, human verification and financial reconciliation.

补充一个真实例子，例如为什么未知金额不能按零处理、为什么 OCR 不直接确认公司、为什么不同币种不能相加。不要填入未经测量的效率提升比例、客户数量或独立开发经历。

## 上传后做什么

1. 在个人主页固定此仓库，About 添加简短英文描述和 python、flask、sqlite、ocr、document-management 等主题。
2. 用虚构演示数据录制 2-3 分钟流程；只上传演示截图或视频，不上传数据库、密码和真实合同。
3. 自己完成并理解一个范围明确的改进，例如增加一种输入验证或补一个迁移边界测试，保留真实提交过程。
4. 练习解释 README 的架构、至少一个完整测试、金额计算和 AI 辅助使用方式。
5. 在 CV 的 Projects 栏写项目名称、真实时间、简短贡献描述和 GitHub 链接。个人陈述只选一个与你申请方向相关的学习收获。

仓库提供的是能力证据，不代替学校的课程先修要求或申请材料要求。本次未评估具体学校的最新录取规则。
